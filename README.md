# CypherV

CypherV is a Vite + React + TypeScript single-page interface with animated UI components.

## Highlights

- Animated hero typography and reveal effects.
- `BorderGlow` card component with edge-reactive glow, gradient mesh, and animated sweep effects.
- Four feature cards showcased below the hero content:
  - 🛡️ Moderation
  - ⚙️ Automation
  - 🧰 Utility
  - ⚡ Performance

## Development

```bash
npm install
npm run dev
```
